Dragonfly — Employee Management & Scheduling System
Dragonfly is a team-developed desktop application created for a Software Engineering course. It was designed to support employee scheduling and administrative tasks through a menu-driven application that communicates with a backend API.

This project gave our team experience collaborating on a shared codebase, integrating individual features, and working with HTTP requests and JSON data.

Features
- Employee Login — authenticates employees through the API and handles login responses.
- Calendar — calendar-related scheduling functionality.
- User Management — functionality for managing user accounts.
- View Feedback — retrieves and displays customer feedback.
- Additional functionality — appointment scheduling and customer-information features.
My Contributions
I worked as part of a team. My primary contributions were:
- Employee Login: Worked on login functionality, including communicating with the API and processing its response.
- Calendar: Contributed to the calendar feature and scheduling-related functionality.
- User Management: Worked on user-management functionality, including adding and editing user information.
- View Feedback: Contributed to retrieving and displaying feedback.
